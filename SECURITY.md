# Security

This tool processes local measurements and JSON backups. It makes no runtime network requests. Do not place private measurements in public issue reports. Report security problems privately through GitHub’s security reporting route when available. Backups and printouts contain the data you entered and are not encrypted. Browser storage is best-effort; keep external backups. JSON imports are bounded, validated and explicitly reviewed before replacement. Do not import untrusted executable files; this tool accepts data only.
